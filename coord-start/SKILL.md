# /coord-start - 初始化联调测试项目

## 🎯 交互式初始化流程

运行 `/coord-start` 后，按照提示选择或输入：

### 📁 步骤 1：选择项目根目录

```
┌─────────────────────────────────────────────────┐
│  📁 项目根目录（当前工作目录）:                   │
│                                                 │
│    ▶ 1️⃣  使用当前目录                          │
│         /home/user/project                      │
│                                                 │
│      2️⃣  输入自定义目录                         │
└─────────────────────────────────────────────────┘
Use ↑/↓ to navigate, Enter to select
```

### 🏷️ 步骤 2：输入需求编号

```
┌─────────────────────────────────────────────────┐
│  🏷️  请输入需求编号:                            │
│                                                 │
│  格式示例: REQ-001, 26RM-001, PRD-2024-Q1-001  │
│  默认: REQ-001                                  │
│                                                 │
│  > _                                           │
└─────────────────────────────────────────────────┘
```

### 👤 步骤 3：选择角色

```
┌─────────────────────────────────────────────────┐
│  👤  请选择你的角色:                             │
│                                                 │
│    ▶ 1️⃣  🔧 后端开发 (backend)                 │
│          配置 API 规则，提供接口文档               │
│                                                 │
│      2️⃣  🎨 前端开发 (frontend)                │
│          对接后端 API，实现页面功能                │
│                                                 │
│      3️⃣  🧪 测试 (testing)                     │
│          执行自动化测试，验证前后端集成            │
└─────────────────────────────────────────────────┘
Use ↑/↓ to navigate, Enter to select
```

### 🔗 步骤 4：根据角色配置

#### 后端开发

```
┌─────────────────────────────────────────────────┐
│  🔧 后端开发配置                                 │
│                                                 │
│  🔗  请输入后端服务 URL:                         │
│  默认: http://localhost:8080                    │
│                                                 │
│  > http://localhost:8080                        │
└─────────────────────────────────────────────────┘
```

还需要配置 API 成功判断规则（在 `/coord-backend-config` 中设置）：
- `api_success_code` - 成功响应 code 值（如 0、200）
- `api_fail_codes` - 失败响应 code 值数组
- `response_data_field` - 数据字段名（如 data）
- `response_code_field` - 状态码字段名（如 code）

#### 前端开发

```
┌─────────────────────────────────────────────────┐
│  🎨 前端开发配置                                 │
│                                                 │
│  🔗  请输入前端服务 URL:                         │
│  默认: http://localhost:5173                    │
│                                                 │
│  > http://localhost:5173                        │
└─────────────────────────────────────────────────┘
```

#### 测试

```
┌─────────────────────────────────────────────────┐
│  🧪 测试配置                                     │
│                                                 │
│  测试会话需要等待以下文件就绪：                   │
│  ✅ backend/api-spec.md                         │
│  ✅ frontend/pages.md                            │
│                                                 │
│  准备好后，运行 /coord-test-start 启动测试        │
└─────────────────────────────────────────────────┘
```

## 💡 快速启动脚本

如果你想要更流畅的交互体验，可以直接运行交互式脚本：

```bash
# 在项目目录下运行
node coord-start/start.js

# 或全局安装后运行
npm install -g coord-start
coord-start
```

这个脚本提供完整的终端菜单式交互，支持：
- ✅ 上下箭头选择
- ✅ Enter 确认
- ✅ 实时预览选择结果

## 📁 创建的目录结构

项目文件将创建在 `{项目根目录}/{需求编号}/` 下:

```
{项目根目录}/{需求编号}/
├── README.md                 # 项目协调手册
├── service-info.json        # 服务配置（URL、状态、API规则）
├── feedback.md             # 统一问题追踪（未关闭）
├── closed.md               # 已关闭问题归档
├── backend/
│   ├── spec.md            # 设计文档
│   ├── plan.md            # 开发计划
│   └── api-spec.md        # 接口规范（联调必需）
├── frontend/
│   ├── spec.md            # 设计文档
│   ├── plan.md            # 开发计划
│   └── pages.md           # 测试页面清单（联调必需）
└── testing/
    ├── test-plan.md       # 测试计划
    ├── session.ts         # Playwright 自动化脚本
    └── reports/
        └── final-report.md
```
