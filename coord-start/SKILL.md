# /coord-start - 初始化联调测试项目

## 输出格式规范

- 使用 Markdown
- 问题编号清晰
- 每个选项用 `- A. xxx`
- 明确说明回复方式

## 禁止行为

- 不要直接写代码
- 不要跳过确认步骤

---

## 交互流程

按顺序逐个问题询问，**每个问题等待用户回复后再问下一个**。

---

### 问题 1：工作目录

```
📁 请输入工作目录路径：

工作目录是所有测试工作的工作目录，会在此生成测试产物
（报告、日志等），与实际的项目目录区分开来。

请输入路径，例如：/home/user/workspace
```

---

### 问题 2：需求编号

```
🏷️ 请输入需求编号：

请输入编号，例如：REQ-001
```

---

### 问题 3：服务配置策略

检查 `{工作目录}/service-info.json` 是否存在：

**如果已存在**：
```
📋 检测到已有服务配置

位置：{工作目录}/service-info.json

请选择需求的服务配置策略：
- A. 沿用已有配置（推荐） - 所有需求共用同一份配置
- B. 创建独立配置 - 本需求使用单独的 service-info.json

请回复，例如：A
```

**如果不存在**：跳过此问题，直接进入问题 4

---

### 问题 4：角色

```
👤 请选择你的角色：
- A. 后端开发 (backend) - 配置 API 规则，提供接口文档
- B. 前端开发 (frontend) - 对接后端 API，实现页面功能
- C. 测试 (testing) - 执行自动化测试，验证前后端集成

请回复，例如：A
```

---

### 问题 5：根据角色配置

#### 如果问题 3 选择了"A. 沿用已有配置"

**后端开发**：
```
✅ 后端将沿用已有配置中的 URL 和 API 规则

请回复任意内容继续：
```

**前端开发**：
```
✅ 前端将沿用已有配置中的 URL

请回复任意内容继续：
```

**测试**：
```
🧪 测试角色说明：
- 测试会话需要等待 backend/api-spec.md 和 frontend/pages.md 就绪
- 准备好后运行 /coord-test-start 启动测试

请回复任意内容继续：
```

#### 如果问题 3 选择了"B. 创建独立配置"或无已有配置

**后端开发**：
```
🔗 请输入后端服务 URL：

请输入 URL，例如：http://localhost:8080
```

然后：
```
🔧 请配置 API 成功判断规则：

- 成功响应的 code 值（默认 0）：0
- 数据字段名（默认 data）：data
- 状态码字段名（默认 code）：code
```

**前端开发**：
```
🔗 请输入前端服务 URL：

请输入 URL，例如：http://localhost:5173
```

**测试**：
```
🧪 测试角色说明：
- 测试会话需要等待 backend/api-spec.md 和 frontend/pages.md 就绪
- 准备好后运行 /coord-test-start 启动测试

请回复任意内容继续：
```

---

### 确认

```
📋 请确认以下信息：

- 工作目录：{工作目录}
- 需求编号：{需求编号}
- 配置策略：{策略}
- 角色：{角色}
- 服务 URL：{url}

确认创建项目？请回复 Y 继续，或回复 N 取消：
```

---

### 创建完成

收到确认后，创建目录和文件：

```bash
mkdir -p {工作目录}/{需求编号}/{backend,frontend,testing/reports}

# 根据配置策略创建或使用 service-info.json

cat > {工作目录}/{需求编号}/README.md << 'EOF'
# {需求编号} 联调测试协调手册

## 项目信息
- 工作目录: {工作目录}
- 需求编号: {需求编号}
- 服务配置: {配置路径}
EOF

cat > {工作目录}/{需求编号}/feedback.md << 'EOF'
# Feedback Log - {需求编号}

## Items
EOF
```

然后输出：
```
✅ 初始化完成！

📁 工作目录：{工作目录}
📋 需求目录：{工作目录}/{需求编号}
📄 服务配置：{配置路径}
👤 角色：{角色}

下一步：
1. /coord-status - 查看状态
2. /coord-poll - 轮询反馈
3. /coord-backend-config - 后端配置
```

## 相关命令

- `/coord-status` - 查看联调状态
- `/coord-poll` - 轮询反馈
- `/coord-backend-config` - 后端配置
